# jiyeon

## 작은 기록들 — 개인 블로그

GitHub Pages에서 바로 호스팅할 수 있는 한국어 개인 블로그입니다. 빌드 도구나 서버가 필요 없는 정적 사이트입니다.

## 시작하기

저장소의 **Settings → Pages**에서 배포 소스를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 선택하면 GitHub Pages가 배포합니다.

## 블로그 꾸미기

- `index.html`에서 블로그 이름, 소개, 이메일 주소를 바꾸세요. `hello@example.com`은 실제 주소로 교체하세요.
- `script.js`의 `posts` 배열에 샘플 글을 수정하거나 새 글을 추가하세요. 날짜는 `YYYY.MM.DD` 형식을 사용합니다.
- `categories`와 `index.html`의 카테고리 카드를 함께 수정하면 카테고리를 바꿀 수 있습니다.
- `style.css`의 `:root` 색상 값을 바꾸면 전체 색감을 조정할 수 있습니다.

현재 글은 편집을 돕기 위한 샘플 콘텐츠이며, 글을 누르면 이메일 초안이 열립니다. 실제 게시물 링크를 만들려면 글별 페이지를 추가해 `script.js`의 링크를 연결하세요.
